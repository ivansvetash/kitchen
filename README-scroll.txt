SIASHOV Kitchens — исправленная полная версия

Восстановлены квиз, общая форма заявки, обработчик api/leads.js, расчёт стоимости
и конфигурация Vercel из версии GitHub до обновления первого экрана.
Видео и постепенное появление элементов при прокрутке сохранены.

Распакуйте архив. Загрузите ВСЁ его содержимое в корень того же репозитория:
включая папку api, папку assets и файлы index.html, app.js, quiz.js, quiz.css,
pricing.js, package.json, vercel.json, style.css, motion.css, hero-scroll.js,
hero-scroll.css. Предварительно удалять файлы не нужно.

В начале виден заголовок. Видео и остальные элементы первого экрана управляются
прокруткой вперёд и назад. Полная анимация — три высоты экрана.
Параметр data-scroll-screens="3" в index.html меняет длину прокрутки.

Заявки отправляются через /api/leads. Сохранён прежний способ настройки:
TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в Environment Variables проекта Vercel.
Секреты в архив не добавлены. Существующие настройки Vercel менять не требуется.

Серверная обработка проверена с имитацией ответа Telegram. Реальная тестовая
заявка не отправлялась. После публикации проверка доставки остаётся необходимой.
