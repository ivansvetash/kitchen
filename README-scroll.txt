SIASHOV Kitchens — версия с исправленной scroll-анимацией первого экрана

Что исправлено:
- Первый экран больше не отключает scroll-анимацию из-за системной настройки
  prefers-reduced-motion. Именно она могла сначала показать первый кадр видео,
  а затем вернуть старую статичную hero-картинку.
- Старый hero.webp больше не используется как fallback первого экрана: при
  проблеме с видео остаётся стартовый кадр новой сцены.
- Скролл по-прежнему занимает ровно 3 высоты экрана (data-scroll-screens="3").
- Заголовок «Кухня, которая подходит именно вам» виден сразу.
- Остальные элементы первого экрана проявляются по мере прокрутки.
- Добавлены cache-busting версии для CSS/JS/video и no-store для HTML на Vercel,
  чтобы после деплоя браузер не подтягивал старую версию первого экрана.
- Квиз, формы заявок, api/leads.js и расчёт стоимости не менялись.

Загружать нужно ВСЁ содержимое архива в корень репозитория с заменой старых файлов.
Environment Variables Vercel для Telegram менять не нужно.
